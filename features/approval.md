# 전자결재

보고가 필요한 근무의 경우 전자결재를 통해 관리가 가능합니다.

## 결재 요청

### 결재 요청 방법

1. **전자결재** > **결재 요청** 클릭
2. 결재 유형 선택
3. 상세 내용 입력
4. 결재선 확인
5. **요청** 버튼 클릭

### 결재 유형

| 유형 | 설명 |
|------|------|
| 휴가 신청 | 연차, 반차 등 휴가 승인 요청 |
| 야근 신청 | 연장 근무 사전 승인 요청 |
| 휴일 근무 | 주말/공휴일 근무 승인 요청 |
| 출장 신청 | 출장 승인 요청 |

## 결재 승인

### 대기 문서 확인

1. **전자결재** 메뉴 클릭
2. **결재 대기** 탭 선택
3. 승인 대기 중인 문서 목록 확인

### 승인 처리

1. 결재 문서 클릭
2. 내용 확인
3. **승인** 또는 **반려** 버튼 클릭

::: warning 반려 시
반려 시에는 반려 사유를 입력해야 합니다.
:::

### 결재선

기본 결재선은 다음과 같습니다:

```
신청자 → 팀장 → (필요시) 부서장
```

## 결재 현황

### 내가 요청한 결재

내가 요청한 결재 문서의 현황을 확인할 수 있습니다.

- **대기**: 결재 진행 중
- **승인**: 결재 완료
- **반려**: 결재 반려됨

### 내가 처리한 결재

내가 승인/반려한 결재 문서 이력을 확인할 수 있습니다.

## 연장 근무와 대체 휴가

### 연장 근무 신청

야근, 휴일 근무 등 연장 근무는 **사전 결재**를 통해 관리됩니다.

1. 근무 전 **야근 신청** 또는 **휴일 근무 신청** 결재 요청
2. 결재 승인 후 근무 수행
3. 근무 완료 후 대체 휴가 발생

### 대체 휴가 부여

승인된 연장 근무에 대해 대체 휴가가 자동으로 부여됩니다.

::: info 대체 휴가 계산
- 야근 4시간 이상: 0.5일
- 휴일 근무 4시간 이상: 0.5일
- 휴일 근무 8시간 이상: 1일
:::
