# 휴가관리

직원들의 휴가 발생과 잔여 일수 관리 등을 체계적으로 관리할 수 있습니다.

## 내 휴가 현황

### 휴가 잔여 일수 확인

1. **휴가관리** 메뉴 클릭
2. 상단에서 **잔여 휴가** 확인
   - 연차
   - 병가
   - 경조사
   - 기타

### 휴가 사용 내역

사용한 휴가 내역을 확인할 수 있습니다.

- 사용일
- 휴가 유형
- 사용 일수
- 승인 상태

## 휴가 신청

### 휴가 신청 방법

1. **휴가관리** > **휴가 신청** 클릭
2. 휴가 정보 입력
   - 휴가 유형 선택 (연차, 반차, 병가 등)
   - 시작일 / 종료일
   - 사유 (선택)
3. **신청** 버튼 클릭

::: info 반차 신청
반차는 오전(09:00-13:00) 또는 오후(14:00-18:00)로 선택할 수 있습니다.
:::

### 휴가 유형

| 유형 | 설명 |
|------|------|
| 연차 | 연간 발생하는 정기 휴가 |
| 반차 | 0.5일 단위의 휴가 |
| 병가 | 질병으로 인한 휴가 |
| 경조사 | 결혼, 출산, 사망 등 |
| 무급휴가 | 급여 공제 휴가 |

## 휴가 승인

### 승인 대기 확인

결재권자는 **전자결재** 메뉴에서 휴가 신청 건을 승인할 수 있습니다.

자세한 내용은 [전자결재](/features/approval) 문서를 참고하세요.

## 휴가 관리 (관리자)

### 휴가 부여

관리자는 직원에게 휴가를 부여할 수 있습니다.

1. **관리자** > **휴가관리** 메뉴 클릭
2. 직원 선택
3. **휴가 부여** 버튼 클릭
4. 휴가 유형 및 일수 입력
5. **저장**

### 전체 휴가 부여

전체 직원에게 일괄로 휴가를 부여할 수 있습니다.

::: tip 연초 연차 부여
매년 1월 전체 직원에게 연차를 일괄 부여할 때 사용합니다.
:::

### 휴가 차감

자동 휴가 차감 기능으로 휴가 사용 시 잔여 일수가 자동으로 계산됩니다.
