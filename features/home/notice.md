# 공지사항

회사 공지사항을 확인할 수 있습니다.

## 공지사항 목록

등록된 공지사항이 최신순으로 표시됩니다.

### 목록 정보

- **제목**: 공지사항 제목
- **작성자**: 공지사항 작성자
- **등록일**: 공지사항 등록 날짜
- **조회수**: 공지사항 조회 횟수

### 중요 공지

중요 표시된 공지사항은 목록 상단에 고정됩니다.

## 공지사항 상세

목록에서 공지사항을 클릭하면 상세 내용을 확인할 수 있습니다.

### 상세 화면 구성

- **제목**
- **작성자 / 등록일**
- **내용**
- **첨부파일** (있는 경우)

### 첨부파일 다운로드

첨부파일이 있는 경우 파일명을 클릭하여 다운로드할 수 있습니다.

## 검색

### 제목 검색

상단 검색창에서 제목으로 공지사항을 검색할 수 있습니다.

1. 검색창에 검색어 입력
2. **검색** 버튼 클릭 또는 Enter

::: info 공지사항 관리
공지사항 등록/수정/삭제는 관리자 권한이 필요합니다.
[공지사항 관리](/admin/notice) 메뉴를 참고하세요.
:::
