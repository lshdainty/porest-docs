# 캘린더

구성원들의 일정을 캘린더 형태로 확인하고 관리할 수 있습니다.

## 캘린더 보기

### 월간 보기

한 달의 일정을 한눈에 확인할 수 있습니다.

- 각 일정은 색상으로 구분됩니다
- 날짜를 클릭하면 해당 일의 상세 일정을 확인할 수 있습니다

### 일정 색상 구분

| 색상 | 일정 유형 |
|------|----------|
| 파랑 | 연차/휴가 |
| 초록 | 출장 |
| 주황 | 교육 |
| 보라 | 예비군 |
| 회색 | 기타 |

## 일정 확인

### 부서별 필터

특정 부서의 일정만 필터링하여 볼 수 있습니다.

1. 캘린더 상단 **필터** 버튼 클릭
2. 원하는 부서 선택
3. **적용** 클릭

### 개인별 필터

특정 구성원의 일정만 필터링하여 볼 수 있습니다.

1. 캘린더 상단 **필터** 버튼 클릭
2. 구성원 이름 검색 또는 선택
3. **적용** 클릭

## 일정 등록

캘린더에서 직접 일정을 등록할 수 있습니다.

### 일정 등록 방법

1. 원하는 날짜 **클릭** 또는 **드래그**
2. 일정 등록 팝업에서 정보 입력
   - 일정 유형 선택
   - 제목 입력
   - 시작일/종료일 확인
   - 메모 (선택)
3. **저장** 버튼 클릭

::: tip 휴가 등록
휴가는 [휴가 신청](/features/vacation/application) 메뉴에서 등록하는 것을 권장합니다.
캘린더에서 등록한 휴가도 결재 프로세스를 거칩니다.
:::

## 일정 수정/삭제

### 수정

1. 캘린더에서 수정할 **일정 클릭**
2. 상세 팝업에서 **수정** 버튼 클릭
3. 정보 수정 후 **저장**

### 삭제

1. 캘린더에서 삭제할 **일정 클릭**
2. 상세 팝업에서 **삭제** 버튼 클릭
3. 삭제 확인

::: warning 승인된 휴가
이미 승인된 휴가 일정은 캘린더에서 직접 삭제할 수 없습니다.
관리자에게 취소 요청하세요.
:::
