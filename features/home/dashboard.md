# 대시보드

로그인 후 가장 먼저 표시되는 메인 화면입니다.

## 화면 구성

대시보드에서는 주요 정보를 한눈에 확인할 수 있습니다.

### 휴가 현황

- **잔여 연차**: 현재 사용 가능한 연차 일수
- **사용 연차**: 올해 사용한 연차 일수
- **총 연차**: 올해 부여된 총 연차 일수

### 오늘의 일정

오늘 예정된 일정이 표시됩니다.

- 휴가 중인 동료
- 출장/교육 일정
- 기타 등록된 일정

### 결재 대기

처리가 필요한 결재 문서가 표시됩니다.

- 내가 요청한 결재 중 대기 중인 건
- (결재권자의 경우) 승인 대기 중인 건

### 공지사항

최근 등록된 공지사항이 표시됩니다.

## 바로가기

대시보드에서 자주 사용하는 기능으로 빠르게 이동할 수 있습니다.

- **휴가 신청** → [휴가 신청](/features/vacation/application) 페이지로 이동
- **캘린더** → [캘린더](/features/home/calendar) 페이지로 이동
- **결재 목록** → 전자결재 페이지로 이동
