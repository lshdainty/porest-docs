# 권한관리

역할 기반 접근 제어(RBAC)를 통해 메뉴 및 기능별 권한을 관리합니다.

## 권한 개요

POREST는 역할 기반 접근 제어(RBAC) 방식으로 권한을 관리합니다.

### 기본 역할

| 역할 | 설명 |
|------|------|
| 일반 사용자 | 기본 기능 사용 |
| 팀장 | 팀원 관리, 결재 승인 |
| 부서장 | 부서 관리, 최종 결재 |
| 관리자 | 시스템 전체 관리 |

## 권한별 접근 메뉴

### 일반 사용자

- 홈 (대시보드, 캘린더)
- 일정관리 (본인)
- 휴가관리 (본인)
- 전자결재 (요청)

### 팀장

일반 사용자 권한 +
- 일정관리 (팀원)
- 휴가관리 (팀원 조회)
- 전자결재 (승인)

### 관리자

모든 메뉴 접근 +
- 사용자 관리
- 부서 관리
- 휴가 부여/관리
- 권한 설정

## 권한 설정 (관리자)

### 사용자별 권한 부여

1. **관리자** > **권한관리** 메뉴 클릭
2. 사용자 검색
3. 권한 항목 체크/해제
4. **저장**

### 세부 권한 설정

메뉴별, 기능별로 세분화된 권한을 부여할 수 있습니다.

| 권한 | 설명 |
|------|------|
| 조회 | 데이터 조회만 가능 |
| 등록 | 새 데이터 등록 가능 |
| 수정 | 기존 데이터 수정 가능 |
| 삭제 | 데이터 삭제 가능 |

::: warning 권한 변경 주의
권한 변경 시 해당 사용자의 접근 가능한 메뉴와 기능이 즉시 변경됩니다.
:::

## 권한에 따른 화면 제어

사용자의 권한에 따라 화면에 표시되는 메뉴와 버튼이 동적으로 제어됩니다.

- 접근 권한이 없는 메뉴는 사이드바에 표시되지 않습니다
- 수정/삭제 권한이 없는 경우 해당 버튼이 비활성화됩니다
