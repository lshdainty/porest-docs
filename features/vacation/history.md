# 휴가 내역

내 휴가 현황과 사용 내역을 확인할 수 있습니다.

## 휴가 현황

### 잔여 휴가

현재 사용 가능한 휴가 일수를 확인할 수 있습니다.

| 구분 | 설명 |
|------|------|
| 연차 | 연간 발생하는 정기 휴가 |
| 보상휴가 | 연장 근무에 대한 대체 휴가 |
| 특별휴가 | 경조사 등 특별 휴가 |

### 휴가 요약

- **총 부여**: 올해 부여된 총 휴가 일수
- **사용**: 올해 사용한 휴가 일수
- **잔여**: 현재 사용 가능한 휴가 일수

## 사용 내역

### 내역 조회

사용한 휴가 내역을 조회할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 휴가 유형 | 연차, 반차, 병가 등 |
| 사용 기간 | 휴가 시작일 ~ 종료일 |
| 사용 일수 | 차감된 휴가 일수 |
| 상태 | 승인됨, 대기중, 반려 |

### 기간 필터

특정 기간의 내역만 조회할 수 있습니다.

1. **시작일** 선택
2. **종료일** 선택
3. **조회** 버튼 클릭

### 상태 필터

특정 상태의 내역만 조회할 수 있습니다.

- 전체
- 승인됨
- 대기중
- 반려

## 발생 내역

### 휴가 발생 이력

휴가가 부여된 이력을 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 발생일 | 휴가가 부여된 날짜 |
| 휴가 유형 | 연차, 보상휴가 등 |
| 발생 일수 | 부여된 휴가 일수 |
| 만료일 | 휴가 사용 기한 (있는 경우) |
| 사유 | 부여 사유 |

::: tip 휴가 신청
새로운 휴가를 신청하려면 [휴가 신청](/features/vacation/application) 메뉴를 이용하세요.
:::
