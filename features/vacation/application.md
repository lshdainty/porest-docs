# 휴가 신청

휴가를 신청하고 관리할 수 있습니다.

## 휴가 신청

### 신청 방법

1. **휴가 신청** 버튼 클릭
2. 휴가 정보 입력
3. **신청** 버튼 클릭

### 입력 항목

| 항목 | 필수 | 설명 |
|------|:---:|------|
| 휴가 유형 | O | 연차, 반차, 병가 등 |
| 시작일 | O | 휴가 시작 날짜 |
| 종료일 | O | 휴가 종료 날짜 |
| 반차 구분 | △ | 오전/오후 (반차 선택 시) |
| 사유 | - | 휴가 사유 |

### 휴가 유형

| 유형 | 차감 | 설명 |
|------|:---:|------|
| 연차 | O | 연간 발생하는 정기 휴가 |
| 반차 | O | 0.5일 단위 휴가 (오전/오후) |
| 병가 | O | 질병으로 인한 휴가 |
| 경조사 | - | 결혼, 출산, 사망 등 (별도 규정) |
| 공가 | - | 예비군, 민방위 등 |
| 무급휴가 | - | 급여 공제 휴가 |

::: info 반차 시간
- **오전 반차**: 09:00 ~ 13:00
- **오후 반차**: 14:00 ~ 18:00
:::

### 연속 휴가

여러 날에 걸친 휴가를 신청할 수 있습니다.

- 시작일과 종료일을 선택하면 자동으로 일수가 계산됩니다
- 주말과 공휴일은 자동으로 제외됩니다

## 신청 내역

### 내역 확인

내가 신청한 휴가 내역을 확인할 수 있습니다.

- **대기중**: 결재 진행 중
- **승인됨**: 결재 완료
- **반려**: 결재 반려됨

### 신청 취소

대기중인 휴가 신청을 취소할 수 있습니다.

1. 취소할 신청 건 선택
2. **취소** 버튼 클릭
3. 취소 확인

::: warning 승인된 휴가 취소
이미 승인된 휴가는 직접 취소할 수 없습니다.
관리자에게 취소 요청하세요.
:::

## 결재 진행

### 결재선

휴가 신청 시 자동으로 결재선이 설정됩니다.

```
신청자 → 팀장 → (필요시) 부서장
```

### 결재 상태 확인

신청 내역에서 현재 결재 진행 상태를 확인할 수 있습니다.

- 결재자별 승인/대기 상태
- 반려 시 반려 사유
