# 업무 일정

팀/부서의 업무 일정을 확인하고 관리합니다.

## 일정 조회

### 일정 목록

등록된 업무 일정을 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 일정명 | 업무 일정 제목 |
| 담당자 | 일정 담당자 |
| 기간 | 시작일 ~ 종료일 |
| 상태 | 진행중, 완료, 지연 등 |

### 필터

#### 기간 필터

특정 기간의 일정만 조회할 수 있습니다.

#### 담당자 필터

특정 담당자의 일정만 조회할 수 있습니다.

#### 상태 필터

특정 상태의 일정만 조회할 수 있습니다.

- 전체
- 진행중
- 완료
- 지연

## 일정 등록

### 등록 방법

1. **일정 등록** 버튼 클릭
2. 일정 정보 입력
3. **저장** 버튼 클릭

### 입력 항목

| 항목 | 필수 | 설명 |
|------|:---:|------|
| 일정명 | O | 업무 일정 제목 |
| 시작일 | O | 일정 시작 날짜 |
| 종료일 | O | 일정 종료 날짜 |
| 담당자 | O | 일정 담당자 |
| 내용 | - | 상세 내용 |

## 일정 수정/삭제

### 수정

1. 수정할 일정 선택
2. **수정** 버튼 클릭
3. 정보 수정 후 **저장**

### 삭제

1. 삭제할 일정 선택
2. **삭제** 버튼 클릭
3. 삭제 확인

## 간트 차트

업무 일정을 간트 차트 형태로 시각화하여 볼 수 있습니다.

### 차트 보기

- 가로축: 날짜/주/월
- 세로축: 업무 일정
- 막대: 일정 기간 표시

### 확대/축소

차트의 시간 단위를 조절할 수 있습니다.

- 일 단위
- 주 단위
- 월 단위
