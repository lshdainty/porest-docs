# 업무 보고

연장 근무(야근, 휴일근무) 신청 및 보고를 관리합니다.

## 업무 보고 신청

### 신청 방법

1. **업무 보고 신청** 버튼 클릭
2. 보고 정보 입력
3. **신청** 버튼 클릭

### 입력 항목

| 항목 | 필수 | 설명 |
|------|:---:|------|
| 보고 유형 | O | 야근, 휴일근무, 출장 등 |
| 근무일 | O | 연장 근무 날짜 |
| 시작 시간 | O | 연장 근무 시작 시간 |
| 종료 시간 | O | 연장 근무 종료 시간 |
| 업무 내용 | O | 수행한 업무 내용 |

### 보고 유형

| 유형 | 설명 | 보상 |
|------|------|------|
| 야근 | 정규 근무 후 연장 근무 | 보상휴가 발생 |
| 휴일근무 | 주말/공휴일 근무 | 보상휴가 발생 |
| 출장 | 외부 출장 | - |
| 교육 | 사내/외부 교육 | - |

## 신청 내역

### 내역 확인

내가 신청한 업무 보고 내역을 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 보고 유형 | 야근, 휴일근무 등 |
| 근무일 | 연장 근무 날짜 |
| 근무 시간 | 시작 ~ 종료 시간 |
| 상태 | 승인됨, 대기중, 반려 |

### 기간 필터

특정 기간의 내역만 조회할 수 있습니다.

## 보상휴가

### 보상휴가 발생 기준

승인된 연장 근무에 대해 보상휴가가 자동으로 발생합니다.

| 구분 | 근무 시간 | 보상휴가 |
|------|----------|----------|
| 야근 | 4시간 이상 | 0.5일 |
| 휴일근무 | 4시간 이상 | 0.5일 |
| 휴일근무 | 8시간 이상 | 1일 |

::: info 보상휴가 확인
발생한 보상휴가는 [휴가 내역](/features/vacation/history)에서 확인할 수 있습니다.
:::

## 결재 진행

### 사전 결재

연장 근무는 **사전 결재**를 원칙으로 합니다.

1. 연장 근무 예정일 **이전**에 신청
2. 결재 승인 후 근무 수행
3. 근무 완료 후 보상휴가 자동 발생

::: warning 사후 보고
부득이하게 사전 결재 없이 연장 근무한 경우, 사후 보고로 신청할 수 있습니다.
단, 사후 보고는 승인이 거부될 수 있습니다.
:::
