# 규정

회사 규정 및 내규를 확인할 수 있습니다.

## 규정 목록

### 목록 조회

등록된 규정 목록을 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 규정명 | 규정 제목 |
| 분류 | 규정 분류 (인사, 복무, 급여 등) |
| 시행일 | 규정 시행 날짜 |
| 버전 | 규정 버전 |

### 분류별 조회

특정 분류의 규정만 조회할 수 있습니다.

- 전체
- 인사 규정
- 복무 규정
- 급여 규정
- 복리후생
- 기타

## 규정 상세

### 상세 내용 확인

목록에서 규정을 클릭하면 상세 내용을 확인할 수 있습니다.

### 첨부파일

규정 원문 파일이 첨부된 경우 다운로드할 수 있습니다.

- PDF, HWP, DOCX 등 지원

## 버전 이력

### 개정 이력

규정의 개정 이력을 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 버전 | 규정 버전 번호 |
| 시행일 | 해당 버전 시행일 |
| 개정 내용 | 주요 개정 사항 |

### 이전 버전 확인

이전 버전의 규정 내용을 확인할 수 있습니다.

::: info 규정 관리
규정 등록 및 수정은 관리자 권한이 필요합니다.
:::
