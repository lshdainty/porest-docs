# 회비

팀/부서 회비 현황을 확인하고 관리합니다.

## 회비 현황

### 잔액 확인

현재 회비 잔액을 확인할 수 있습니다.

- **총 잔액**: 현재 사용 가능한 회비
- **이번 달 입금**: 이번 달 입금된 금액
- **이번 달 지출**: 이번 달 사용된 금액

## 입출금 내역

### 내역 조회

회비 입출금 내역을 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 일자 | 입출금 날짜 |
| 구분 | 입금/지출 |
| 금액 | 입출금 금액 |
| 내용 | 입출금 내용 |
| 잔액 | 거래 후 잔액 |

### 기간 필터

특정 기간의 내역만 조회할 수 있습니다.

1. **시작일** 선택
2. **종료일** 선택
3. **조회** 버튼 클릭

### 구분 필터

입금 또는 지출 내역만 필터링할 수 있습니다.

- 전체
- 입금
- 지출

## 회비 납부

### 납부 방법

회비 납부는 매월 급여에서 자동 공제되거나, 별도 입금으로 처리됩니다.

### 납부 현황

내 회비 납부 현황을 확인할 수 있습니다.

- **납부 완료**: 정상 납부됨
- **미납**: 납부 필요

::: info 회비 관리
회비 입출금 등록 및 관리는 담당자 권한이 필요합니다.
:::
