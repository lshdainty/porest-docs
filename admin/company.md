# 회사 관리

회사 기본 정보를 관리합니다.

::: warning 관리자 전용
이 메뉴는 **COMPANY:MANAGE** 권한이 필요합니다.
:::

## 회사 정보

### 기본 정보

회사의 기본 정보를 확인하고 수정할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 회사명 | 회사 이름 |
| 사업자등록번호 | 사업자등록번호 |
| 대표자 | 대표자 이름 |
| 주소 | 회사 주소 |
| 연락처 | 대표 전화번호 |

### 정보 수정

1. 수정할 항목의 값 변경
2. **저장** 버튼 클릭

## 근무 설정

### 기본 근무 시간

회사의 기본 근무 시간을 설정합니다.

| 항목 | 기본값 | 설명 |
|------|--------|------|
| 출근 시간 | 09:00 | 정규 출근 시간 |
| 퇴근 시간 | 18:00 | 정규 퇴근 시간 |
| 점심 시간 | 12:00~13:00 | 점심 휴게 시간 |

### 주간 근무일

- 주 5일 근무 (월~금)
- 주 6일 근무 (월~토) 등 설정 가능

## 로고 설정

### 로고 변경

회사 로고를 변경할 수 있습니다.

1. **로고 변경** 버튼 클릭
2. 이미지 파일 선택
3. **저장** 버튼 클릭

::: tip 권장 사양
- 형식: PNG, JPG
- 크기: 200x50px 권장
- 파일 크기: 1MB 이하
:::
