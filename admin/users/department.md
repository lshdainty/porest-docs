# 부서 관리

부서(조직)를 등록하고 관리합니다.

::: warning 관리자 전용
이 메뉴는 **USER:MANAGE** 권한이 필요합니다.
:::

## 조직도

### 조직 구조

트리 형태로 조직 구조를 확인할 수 있습니다.

```
회사
├── 경영지원팀
├── 개발팀
│   ├── 프론트엔드
│   └── 백엔드
├── 영업팀
└── ...
```

### 부서 선택

조직도에서 부서를 클릭하면 해당 부서의 상세 정보와 소속 인원을 확인할 수 있습니다.

## 부서 등록

### 등록 방법

1. 상위 부서 선택 (또는 최상위에 등록)
2. **부서 추가** 버튼 클릭
3. 부서 정보 입력
4. **저장** 버튼 클릭

### 입력 항목

| 항목 | 필수 | 설명 |
|------|:---:|------|
| 부서명 | O | 부서 이름 |
| 부서코드 | O | 부서 고유 코드 |
| 상위부서 | - | 상위 부서 (미선택 시 최상위) |
| 정렬순서 | - | 조직도 표시 순서 |

## 부서 수정

### 정보 수정

1. 수정할 부서 선택
2. **수정** 버튼 클릭
3. 정보 수정 후 **저장**

### 상위 부서 변경

부서의 상위 부서를 변경하여 조직 구조를 변경할 수 있습니다.

::: warning 하위 부서 포함
상위 부서 변경 시 하위 부서도 함께 이동됩니다.
:::

## 부서 삭제

### 삭제 조건

다음 조건을 만족해야 부서를 삭제할 수 있습니다.

- 소속 인원이 없어야 함
- 하위 부서가 없어야 함

### 삭제 방법

1. 삭제할 부서 선택
2. **삭제** 버튼 클릭
3. 삭제 확인

## 소속 인원

### 인원 확인

부서를 선택하면 소속 인원 목록을 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 이름 | 사용자 이름 |
| 직급 | 직급 |
| 연락처 | 전화번호 |
| 이메일 | 이메일 주소 |

### 부서 이동

사용자의 소속 부서를 변경할 수 있습니다.

1. 이동할 사용자 선택
2. **부서 이동** 버튼 클릭
3. 이동할 부서 선택
4. **확인**
