# 사용자 관리

사용자 계정을 등록하고 관리합니다.

::: warning 관리자 전용
이 메뉴는 **USER:MANAGE** 권한이 필요합니다.
:::

## 사용자 목록

### 목록 조회

등록된 사용자를 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 이름 | 사용자 이름 |
| 아이디 | 로그인 아이디 |
| 부서 | 소속 부서 |
| 직급 | 직급 |
| 입사일 | 입사 날짜 |
| 상태 | 재직/휴직/퇴사 |

### 검색

사용자를 검색할 수 있습니다.

- 이름 검색
- 아이디 검색
- 부서 검색

### 필터

특정 조건의 사용자만 조회할 수 있습니다.

- 부서별
- 상태별 (재직/휴직/퇴사)

## 사용자 등록

### 등록 방법

1. **사용자 등록** 버튼 클릭
2. 사용자 정보 입력
3. **저장** 버튼 클릭

### 입력 항목

| 항목 | 필수 | 설명 |
|------|:---:|------|
| 아이디 | O | 로그인 아이디 |
| 이름 | O | 사용자 이름 |
| 비밀번호 | O | 초기 비밀번호 |
| 이메일 | O | 이메일 주소 |
| 부서 | O | 소속 부서 |
| 직급 | O | 직급 |
| 입사일 | O | 입사 날짜 |
| 연락처 | - | 전화번호 |

## 사용자 수정

### 정보 수정

1. 수정할 사용자 선택
2. **수정** 버튼 클릭
3. 정보 수정 후 **저장**

### 비밀번호 초기화

사용자 비밀번호를 초기화할 수 있습니다.

1. 사용자 선택
2. **비밀번호 초기화** 버튼 클릭
3. 초기화 확인

::: info 초기 비밀번호
초기화된 비밀번호는 사용자에게 별도 안내해야 합니다.
:::

## 사용자 상태

### 상태 변경

사용자의 재직 상태를 변경할 수 있습니다.

| 상태 | 설명 |
|------|------|
| 재직 | 정상 근무 중 |
| 휴직 | 휴직 중 (로그인 불가) |
| 퇴사 | 퇴사 처리됨 (로그인 불가) |

### 퇴사 처리

1. 퇴사할 사용자 선택
2. **퇴사 처리** 버튼 클릭
3. 퇴사일 입력
4. **확인**

::: warning 퇴사 처리 주의
퇴사 처리된 사용자는 로그인할 수 없습니다.
퇴사 처리 전 휴가 정산 등을 완료하세요.
:::
