# 업무 코드

업무 보고에 사용되는 업무 코드를 관리합니다.

::: warning 관리자 전용
이 메뉴는 **WORK:MANAGE** 권한이 필요합니다.
:::

## 업무 코드 목록

### 목록 조회

등록된 업무 코드를 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 코드 | 업무 코드 |
| 코드명 | 업무 코드 이름 |
| 설명 | 코드 설명 |
| 사용여부 | 활성화/비활성화 |

## 업무 코드 등록

### 등록 방법

1. **코드 등록** 버튼 클릭
2. 코드 정보 입력
   - 코드
   - 코드명
   - 설명
3. **저장** 버튼 클릭

### 입력 항목

| 항목 | 필수 | 설명 |
|------|:---:|------|
| 코드 | O | 고유 업무 코드 (영문, 숫자) |
| 코드명 | O | 업무 코드 이름 |
| 설명 | - | 코드에 대한 상세 설명 |
| 정렬순서 | - | 목록 표시 순서 |

## 업무 코드 수정/삭제

### 수정

1. 수정할 코드 선택
2. **수정** 버튼 클릭
3. 정보 수정 후 **저장**

### 비활성화

사용하지 않는 코드는 삭제 대신 비활성화를 권장합니다.

1. 비활성화할 코드 선택
2. **사용여부**를 '미사용'으로 변경
3. **저장**

::: info 코드 삭제
이미 사용된 코드는 삭제할 수 없습니다.
비활성화하여 더 이상 선택되지 않도록 처리하세요.
:::
