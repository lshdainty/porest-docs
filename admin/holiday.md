# 공휴일 관리

공휴일을 등록하고 관리합니다.

::: warning 관리자 전용
이 메뉴는 **HOLIDAY:MANAGE** 권한이 필요합니다.
:::

## 공휴일 목록

### 목록 조회

등록된 공휴일 목록을 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 날짜 | 공휴일 날짜 |
| 공휴일명 | 공휴일 이름 |
| 유형 | 법정공휴일, 대체공휴일, 회사지정휴일 |

### 연도 필터

특정 연도의 공휴일만 조회할 수 있습니다.

## 공휴일 등록

### 개별 등록

1. **공휴일 등록** 버튼 클릭
2. 공휴일 정보 입력
   - 날짜
   - 공휴일명
   - 유형
3. **저장** 버튼 클릭

### 일괄 등록

연간 법정공휴일을 일괄 등록할 수 있습니다.

1. **일괄 등록** 버튼 클릭
2. 연도 선택
3. 등록할 공휴일 선택
4. **저장** 버튼 클릭

::: tip 법정공휴일 자동 등록
매년 초 법정공휴일을 자동으로 불러와 등록할 수 있습니다.
:::

## 공휴일 수정/삭제

### 수정

1. 수정할 공휴일 선택
2. **수정** 버튼 클릭
3. 정보 수정 후 **저장**

### 삭제

1. 삭제할 공휴일 선택
2. **삭제** 버튼 클릭
3. 삭제 확인

## 공휴일 유형

| 유형 | 설명 |
|------|------|
| 법정공휴일 | 법으로 지정된 공휴일 |
| 대체공휴일 | 공휴일이 주말과 겹칠 때 대체 지정 |
| 회사지정휴일 | 회사에서 별도 지정한 휴일 |
| 창립기념일 | 회사 창립기념일 |
