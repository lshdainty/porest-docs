# 휴가 정책

휴가 발생 및 사용에 대한 정책을 설정합니다.

::: warning 관리자 전용
이 메뉴는 **VACATION:MANAGE** 권한이 필요합니다.
:::

## 연차 정책

### 연차 발생 기준

연차 발생 기준을 설정할 수 있습니다.

| 설정 | 설명 |
|------|------|
| 발생 기준 | 회계년도 / 입사일 기준 |
| 발생 시점 | 연초 일괄 / 월별 발생 |
| 기본 연차 | 연간 기본 발생 일수 |

### 근속 가산

근속 연수에 따른 추가 연차를 설정할 수 있습니다.

| 근속 연수 | 추가 연차 |
|----------|----------|
| 3년 이상 | +1일 |
| 5년 이상 | +2일 |
| 10년 이상 | +3일 |

## 휴가 유형 설정

### 유형 목록

사용 가능한 휴가 유형을 관리합니다.

| 항목 | 설명 |
|------|------|
| 유형명 | 휴가 유형 이름 |
| 차감여부 | 연차에서 차감 여부 |
| 승인필요 | 결재 승인 필요 여부 |
| 사용여부 | 활성화/비활성화 |

### 유형 추가

1. **유형 추가** 버튼 클릭
2. 유형 정보 입력
3. **저장** 버튼 클릭

## 사용 제한

### 최소 신청 기한

휴가 신청 시 최소 사전 신청 기한을 설정할 수 있습니다.

- 예: 휴가 시작 3일 전까지 신청

### 연속 사용 제한

연속 사용 가능한 최대 일수를 설정할 수 있습니다.

- 예: 연속 5일까지만 사용 가능

### 월별 사용 제한

월별 최대 사용 가능 일수를 설정할 수 있습니다.

## 이월 정책

### 연차 이월

미사용 연차의 이월 정책을 설정합니다.

| 설정 | 옵션 |
|------|------|
| 이월 여부 | 허용 / 불허 |
| 이월 한도 | 최대 이월 가능 일수 |
| 사용 기한 | 이월된 연차 사용 기한 |

::: info 연차 소멸
이월되지 않거나 사용 기한이 지난 연차는 자동 소멸됩니다.
:::
