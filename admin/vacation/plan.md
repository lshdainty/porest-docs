# 휴가 계획

휴가 부여 계획을 수립하고 실행합니다.

::: warning 관리자 전용
이 메뉴는 **VACATION:MANAGE** 권한이 필요합니다.
:::

## 휴가 부여

### 개별 부여

특정 사용자에게 휴가를 부여합니다.

1. **휴가 부여** 버튼 클릭
2. 대상 사용자 선택
3. 부여 정보 입력
   - 휴가 유형
   - 부여 일수
   - 사유
4. **저장** 버튼 클릭

### 일괄 부여

전체 또는 특정 그룹에 휴가를 일괄 부여합니다.

1. **일괄 부여** 버튼 클릭
2. 대상 선택 (전체 / 부서별 / 조건별)
3. 부여 정보 입력
4. **저장** 버튼 클릭

::: tip 연초 연차 부여
매년 연초에 전체 직원에게 연차를 일괄 부여할 때 사용합니다.
:::

## 부여 내역

### 내역 조회

휴가 부여 내역을 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 부여일 | 휴가 부여 날짜 |
| 대상자 | 휴가 부여 대상 |
| 휴가 유형 | 연차, 보상휴가 등 |
| 부여 일수 | 부여된 휴가 일수 |
| 사유 | 부여 사유 |

### 필터

- 기간 필터
- 사용자 필터
- 휴가 유형 필터

## 휴가 차감

### 차감 방법

특정 사용자의 휴가를 차감합니다.

1. **휴가 차감** 버튼 클릭
2. 대상 사용자 선택
3. 차감 정보 입력
   - 휴가 유형
   - 차감 일수
   - 사유
4. **저장** 버튼 클릭

::: warning 차감 주의
차감은 잔여 휴가 일수를 감소시킵니다.
잔여 일수보다 많이 차감할 수 없습니다.
:::

## 휴가 현황

### 전체 현황

전체 사용자의 휴가 현황을 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 사용자 | 사용자 이름 |
| 부서 | 소속 부서 |
| 총 부여 | 부여된 휴가 일수 |
| 사용 | 사용한 휴가 일수 |
| 잔여 | 잔여 휴가 일수 |

### 엑셀 다운로드

휴가 현황을 엑셀 파일로 다운로드할 수 있습니다.

1. 조회 조건 설정
2. **엑셀 다운로드** 버튼 클릭
