# 휴가 승인

휴가 신청을 승인하고 관리합니다.

::: warning 관리자 전용
이 메뉴는 **VACATION:APPROVE** 권한이 필요합니다.
:::

## 승인 대기

### 대기 목록

승인 대기 중인 휴가 신청 목록을 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 신청자 | 휴가 신청자 |
| 휴가 유형 | 연차, 반차, 병가 등 |
| 기간 | 휴가 시작일 ~ 종료일 |
| 일수 | 휴가 일수 |
| 신청일 | 휴가 신청 날짜 |
| 사유 | 휴가 사유 |

### 필터

- 부서별 필터
- 휴가 유형별 필터
- 기간 필터

## 승인 처리

### 개별 승인

1. 승인할 신청 선택
2. **승인** 버튼 클릭
3. 승인 확인

### 일괄 승인

여러 건을 한번에 승인할 수 있습니다.

1. 승인할 신청 다중 선택 (체크박스)
2. **일괄 승인** 버튼 클릭
3. 승인 확인

## 반려 처리

### 반려 방법

1. 반려할 신청 선택
2. **반려** 버튼 클릭
3. 반려 사유 입력
4. **확인**

::: info 반려 사유
반려 시 반드시 사유를 입력해야 합니다.
입력된 사유는 신청자에게 안내됩니다.
:::

## 승인 내역

### 처리 내역 조회

승인/반려 처리한 내역을 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 신청자 | 휴가 신청자 |
| 휴가 유형 | 연차, 반차, 병가 등 |
| 기간 | 휴가 시작일 ~ 종료일 |
| 처리일 | 승인/반려 처리 날짜 |
| 처리결과 | 승인/반려 |

## 휴가 취소

### 승인 취소

이미 승인된 휴가를 취소할 수 있습니다.

1. 취소할 휴가 선택
2. **승인 취소** 버튼 클릭
3. 취소 사유 입력
4. **확인**

::: warning 취소 주의
이미 사용한 휴가는 취소할 수 없습니다.
휴가 시작일 이전에만 취소 가능합니다.
:::
