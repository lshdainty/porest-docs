# 공지사항 관리

공지사항을 등록하고 관리합니다.

::: warning 관리자 전용
이 메뉴는 **NOTICE:MANAGE** 권한이 필요합니다.
:::

## 공지사항 목록

### 목록 조회

등록된 공지사항을 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 제목 | 공지사항 제목 |
| 작성자 | 공지사항 작성자 |
| 등록일 | 공지사항 등록 날짜 |
| 조회수 | 공지사항 조회 횟수 |
| 중요 | 중요 공지 여부 |

## 공지사항 등록

### 등록 방법

1. **공지사항 등록** 버튼 클릭
2. 공지사항 정보 입력
3. **저장** 버튼 클릭

### 입력 항목

| 항목 | 필수 | 설명 |
|------|:---:|------|
| 제목 | O | 공지사항 제목 |
| 내용 | O | 공지사항 본문 |
| 중요 | - | 중요 공지 여부 (상단 고정) |
| 첨부파일 | - | 첨부할 파일 |

### 에디터 기능

본문 작성 시 다양한 서식을 사용할 수 있습니다.

- 굵게, 기울임, 밑줄
- 목록 (번호, 글머리)
- 링크 삽입
- 이미지 삽입

### 첨부파일

파일을 첨부할 수 있습니다.

- 최대 파일 크기: 10MB
- 최대 파일 개수: 5개

## 공지사항 수정/삭제

### 수정

1. 수정할 공지사항 선택
2. **수정** 버튼 클릭
3. 내용 수정 후 **저장**

### 삭제

1. 삭제할 공지사항 선택
2. **삭제** 버튼 클릭
3. 삭제 확인

## 중요 공지

### 중요 표시

중요한 공지사항은 상단에 고정할 수 있습니다.

1. 공지사항 등록/수정 시 **중요** 체크
2. **저장**

중요 표시된 공지사항은 목록 상단에 항상 표시됩니다.
