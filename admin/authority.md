# 권한 설정

사용자 역할 및 권한을 설정합니다.

::: warning 관리자 전용
이 메뉴는 **ROLE:MANAGE** 권한이 필요합니다.
:::

## 역할 관리

### 역할 목록

등록된 역할을 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 역할명 | 역할 이름 |
| 설명 | 역할 설명 |
| 사용자 수 | 해당 역할이 부여된 사용자 수 |

### 기본 역할

시스템에 기본 제공되는 역할입니다.

| 역할 | 설명 |
|------|------|
| 일반 사용자 | 기본 기능 사용 |
| 팀장 | 팀원 관리, 결재 승인 |
| 관리자 | 시스템 전체 관리 |

## 역할 등록

### 등록 방법

1. **역할 등록** 버튼 클릭
2. 역할 정보 입력
   - 역할명
   - 설명
3. 권한 선택
4. **저장** 버튼 클릭

## 권한 설정

### 권한 목록

각 역할에 부여할 수 있는 권한입니다.

| 권한 | 설명 |
|------|------|
| VACATION:READ | 휴가 조회 |
| VACATION:REQUEST | 휴가 신청 |
| VACATION:APPROVE | 휴가 승인 |
| VACATION:MANAGE | 휴가 관리 |
| USER:MANAGE | 사용자 관리 |
| COMPANY:MANAGE | 회사 관리 |
| ROLE:MANAGE | 권한 관리 |
| NOTICE:READ | 공지사항 조회 |
| NOTICE:MANAGE | 공지사항 관리 |
| WORK:READ | 업무 조회 |
| WORK:MANAGE | 업무 관리 |
| HOLIDAY:MANAGE | 공휴일 관리 |
| DUES:READ | 회비 조회 |
| REGULATION:READ | 규정 조회 |

### 권한 부여

역할에 권한을 부여합니다.

1. 역할 선택
2. 부여할 권한 체크
3. **저장** 버튼 클릭

## 사용자별 역할 부여

### 역할 부여 방법

사용자에게 역할을 부여합니다.

1. 사용자 검색/선택
2. 부여할 역할 선택
3. **저장** 버튼 클릭

### 다중 역할

한 사용자에게 여러 역할을 부여할 수 있습니다.
부여된 모든 역할의 권한을 갖게 됩니다.

::: info 권한 적용
역할 변경 시 해당 사용자의 접근 가능한 메뉴가 즉시 변경됩니다.
:::
