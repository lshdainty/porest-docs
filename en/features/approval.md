# Electronic Approval

Manage work that requires reporting through electronic approval.

## Request Approval

### How to Request

1. Click **Electronic Approval** > **Request Approval**
2. Select approval type
3. Enter details
4. Confirm approval line
5. Click **Request** button

### Approval Types

| Type | Description |
|------|------|
| Vacation Request | Request approval for annual, half-day leave, etc. |
| Overtime Request | Request pre-approval for extended work |
| Holiday Work | Request approval for weekend/holiday work |
| Business Trip | Request approval for business trips |

## Approve Documents

### Check Pending

1. Click **Electronic Approval** menu
2. Select **Pending** tab
3. Check list of documents awaiting approval

### Process Approval

1. Click approval document
2. Review content
3. Click **Approve** or **Reject** button

::: warning When Rejecting
A rejection reason must be entered when rejecting.
:::

### Approval Line

The default approval line is:

```
Requester → Team Leader → (if needed) Department Head
```

## Approval Status

### My Requests

Check the status of approval documents you requested.

- **Pending**: Approval in progress
- **Approved**: Approval completed
- **Rejected**: Approval rejected

### My Processed

Check history of documents you approved/rejected.

## Overtime and Compensatory Leave

### Overtime Request

Extended work such as overtime and holiday work is managed through **pre-approval**.

1. Request **Overtime** or **Holiday Work** approval before work
2. Perform work after approval
3. Compensatory leave generated after work completion

### Compensatory Leave Grant

Compensatory leave is automatically granted for approved extended work.

::: info Compensatory Leave Calculation
- Overtime 4+ hours: 0.5 day
- Holiday work 4+ hours: 0.5 day
- Holiday work 8+ hours: 1 day
:::
