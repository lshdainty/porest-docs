# Company Regulations

View company rules and regulations.

## Regulation Categories

### Category List

View regulations by category.

| Category | Description |
|----------|-------------|
| Employment | Employment rules |
| Leave | Leave policies |
| Benefits | Welfare and benefits |
| Others | Other regulations |

## View Regulations

### Regulation List

View list of regulations.

| Item | Description |
|------|-------------|
| Title | Regulation name |
| Category | Regulation category |
| Version | Current version |
| Effective Date | Effective date |

### View Details

Click a regulation to view its full content.

- Table of contents
- Full text
- Attached files

## File Download

### Download Regulations

Download regulation documents.

1. Open regulation details
2. Click file download button
3. Download starts automatically

::: tip Tip
Check the effective date when viewing regulations. Previous versions may be archived.
:::
