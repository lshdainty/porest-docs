# Leave Request

Request leave.

## New Request

### Request Process

1. Click **Request Leave** button
2. Enter leave information
3. Click **Submit** button

### Input Fields

| Field | Required | Description |
|-------|:--------:|-------------|
| Leave Type | O | Annual, half-day, sick leave, etc. |
| Start Date | O | Leave start date |
| End Date | O | Leave end date |
| Reason | O | Leave reason |

### Leave Types

| Type | Description |
|------|-------------|
| Annual Leave | Use from annual leave balance |
| Morning Half | Morning half-day (counts as 0.5 days) |
| Afternoon Half | Afternoon half-day (counts as 0.5 days) |
| Sick Leave | Leave due to illness |
| Special Leave | Events like weddings, funerals |

## My Requests

### Check Status

Check the status of submitted requests.

| Status | Description |
|--------|-------------|
| Pending | Waiting for approval |
| Approved | Request approved |
| Rejected | Request rejected |

### Cancel Request

Cancel a pending request.

1. Select request to cancel
2. Click **Cancel** button
3. Confirm cancellation

::: warning Note
Only pending requests can be cancelled.
:::
