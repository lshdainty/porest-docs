# Leave History

Check your leave usage history and remaining balance.

## Leave Balance

### Balance Overview

View your current leave balance.

| Item | Description |
|------|-------------|
| Total Granted | Total granted leave days |
| Used | Used leave days |
| Remaining | Remaining leave days |

### By Leave Type

View balance breakdown by leave type.

- Annual leave
- Sick leave
- Compensatory leave
- Other

## Usage History

### History List

View your leave usage history.

| Item | Description |
|------|-------------|
| Period | Leave start ~ end date |
| Type | Leave type |
| Days | Number of days used |
| Status | Approved/Rejected/Pending |

### Filter

- By period
- By leave type
- By status

## Detail View

### View Details

Click a leave record to view details.

- Applied leave information
- Approval details
- Approval/rejection reason
