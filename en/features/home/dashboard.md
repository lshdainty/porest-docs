# Dashboard

The main screen after logging in. You can check key information at a glance.

## Overview

### Today's Information

Check key information for today.

| Item | Description |
|------|-------------|
| Date | Today's date and day of week |
| Weather | Current weather information |
| Remaining Leave | Remaining annual leave |

### Upcoming Schedule

Displays upcoming schedules.

- Leave schedule
- Work schedule
- Company events

### Recent Notices

Shows the latest notices. Click to view details.

## Quick Actions

### Available Actions

| Button | Description |
|--------|-------------|
| Request Leave | Go to leave request page |
| Write Report | Go to work report page |
| View Calendar | Go to calendar page |
