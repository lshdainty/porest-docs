# Notices

View and manage company notices.

## Notice List

### List View

View all notices in a list.

| Item | Description |
|------|-------------|
| Title | Notice title |
| Author | Person who posted |
| Date | Posted date |
| Views | Number of views |
| Pinned | Important notice marker |

### Filter

- All notices
- Pinned notices only
- By category

## Notice Detail

### View Details

Click a notice to view its full content.

- Title
- Author and date
- Content
- Attached files

### File Download

If there are attached files, you can download them.

1. Click file name
2. Download starts automatically

## Search

### Search by Keyword

Search notices by keyword.

1. Enter keyword in search box
2. Press Enter or click search button
3. View matching results
