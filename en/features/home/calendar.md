# Calendar

View all schedules at a glance including leave and work schedules.

## Calendar View

### View Mode

You can switch between view modes.

| Mode | Description |
|------|-------------|
| Monthly | Full month view |
| Weekly | Week view |
| Daily | Day view |

### Schedule Display

Different schedule types are distinguished by color.

| Color | Schedule Type |
|-------|---------------|
| Blue | My leave |
| Green | Team leave |
| Orange | Work schedule |
| Red | Holidays |

## Schedule Management

### View Details

Click on a schedule to view its details.

- Leave: Requester, type, period, reason
- Work: Title, content, attendees

### Filter

Filter schedules you want to see.

- My schedule only
- Team schedule
- By leave type
- By work type

## Month Navigation

Use arrows to move to previous/next month.
Click "Today" button to return to current month.
