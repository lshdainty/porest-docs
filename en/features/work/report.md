# Work Report

Write and manage work reports.

## Write Report

### New Report

1. Click **Write Report** button
2. Enter report content
3. Click **Submit** button

### Input Fields

| Field | Required | Description |
|-------|:--------:|-------------|
| Title | O | Report title |
| Report Date | O | Report date |
| Content | O | Work content |
| Attachments | - | Attach files |

### Report Types

| Type | Description |
|------|-------------|
| Daily Report | Daily work report |
| Weekly Report | Weekly work summary |
| Monthly Report | Monthly work summary |

## Report List

### View Reports

View submitted reports.

| Item | Description |
|------|-------------|
| Title | Report title |
| Report Date | Report date |
| Status | Submitted/Draft |
| Written Date | Date created |

### Filter

- By period
- By report type
- By status

## Report Management

### Edit

Edit saved reports.

1. Select report to edit
2. Click **Edit** button
3. Modify content
4. Click **Save**

### Delete

Delete reports.

1. Select report to delete
2. Click **Delete** button
3. Confirm deletion
