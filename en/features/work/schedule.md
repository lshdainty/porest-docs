# Work Schedule

Manage work schedules.

## Schedule Registration

### New Schedule

1. Click **Add Schedule** button
2. Enter schedule information
3. Click **Save** button

### Input Fields

| Field | Required | Description |
|-------|:--------:|-------------|
| Title | O | Schedule title |
| Start | O | Start date and time |
| End | O | End date and time |
| Description | - | Detailed description |
| Participants | - | Schedule participants |

## Schedule List

### View Schedules

View registered schedules.

| Item | Description |
|------|-------------|
| Title | Schedule title |
| Period | Start ~ End |
| Participants | Number of participants |

### Calendar View

View schedules in calendar format.

- Monthly/Weekly/Daily view available
- Click schedule to view details

## Schedule Management

### Edit Schedule

1. Select schedule to edit
2. Click **Edit** button
3. Modify information
4. Click **Save**

### Delete Schedule

1. Select schedule to delete
2. Click **Delete** button
3. Confirm deletion

### Add Participants

Add participants to a schedule.

1. Open schedule details
2. Click **Add Participants**
3. Select users
4. Click **Save**
