# Vacation Management

Systematically manage employee vacation accrual and remaining days.

## My Vacation Status

### Check Remaining Days

1. Click **Vacation Management** menu
2. Check **Remaining Vacation** at the top
   - Annual leave
   - Sick leave
   - Family events
   - Others

### Usage History

View your vacation usage history.

- Date used
- Vacation type
- Days used
- Approval status

## Apply for Vacation

### How to Apply

1. Click **Vacation Management** > **Apply for Vacation**
2. Enter vacation information
   - Select vacation type (Annual, Half-day, Sick, etc.)
   - Start date / End date
   - Reason (optional)
3. Click **Apply** button

::: info Half-day Application
Half-day can be selected as morning (09:00-13:00) or afternoon (14:00-18:00).
:::

### Vacation Types

| Type | Description |
|------|------|
| Annual | Regular annual leave |
| Half-day | 0.5-day vacation |
| Sick | Leave due to illness |
| Family Event | Marriage, birth, death, etc. |
| Unpaid | Leave with pay deduction |

## Vacation Approval

### Check Pending

Approvers can approve vacation requests in the **Electronic Approval** menu.

See [Electronic Approval](/en/features/approval) for details.

## Vacation Management (Admin)

### Grant Vacation

Administrators can grant vacations to employees.

1. Click **Admin** > **Vacation Management** menu
2. Select employee
3. Click **Grant Vacation** button
4. Enter vacation type and days
5. **Save**

### Bulk Grant

Grant vacations to all employees at once.

::: tip Annual Leave at Year Start
Use this to bulk grant annual leave to all employees in January.
:::

### Automatic Deduction

Remaining days are automatically calculated when vacations are used.
