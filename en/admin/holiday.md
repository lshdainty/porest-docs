# Holiday Management

Register and manage public holidays.

::: warning Admin Only
This menu requires **HOLIDAY:MANAGE** permission.
:::

## Holiday List

### View Holidays

View list of registered holidays.

| Item | Description |
|------|-------------|
| Date | Holiday date |
| Name | Holiday name |
| Type | National/Company holiday |
| Annual | Recurring annually |

### Filter

- By year
- By holiday type

## Add Holiday

### Add Method

1. Click **Add Holiday** button
2. Enter holiday information
3. Click **Save** button

### Input Fields

| Field | Required | Description |
|-------|:--------:|-------------|
| Date | O | Holiday date |
| Name | O | Holiday name |
| Type | O | National/Company |
| Annual | - | Recur every year |

## Edit Holiday

### Edit Method

1. Select holiday to edit
2. Click **Edit** button
3. Modify information
4. Click **Save**

### Delete Method

1. Select holiday to delete
2. Click **Delete** button
3. Confirm deletion

## Bulk Registration

### Register Multiple Holidays

Register national holidays in bulk.

1. Click **Bulk Registration** button
2. Select year
3. Check holidays to add
4. Click **Save**

::: info Holiday Calendar
Holiday information is reflected in the calendar view.
:::
