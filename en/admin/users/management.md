# User Management

Register and manage users.

::: warning Admin Only
This menu requires **USER:MANAGE** permission.
:::

## User List

### View Users

View all registered users.

| Item | Description |
|------|-------------|
| Name | User name |
| Employee ID | Employee ID |
| Department | Department |
| Position | Job position |
| Status | Active/Inactive |

### Search

Search users by name or employee ID.

### Filter

- By department
- By position
- By status

## Add User

### Add Method

1. Click **Add User** button
2. Enter user information
3. Click **Save** button

### Input Fields

| Field | Required | Description |
|-------|:--------:|-------------|
| Name | O | User name |
| Employee ID | O | Employee ID |
| Email | O | Email address |
| Department | O | Department |
| Position | - | Job position |
| Join Date | O | Date of joining |
| Phone | - | Phone number |

## Edit User

### Information Edit

1. Select user
2. Click **Edit** button
3. Modify information
4. Click **Save**

### Status Change

Change user status (Active/Inactive).

1. Select user
2. Click **Change Status** button
3. Select status
4. Confirm

::: info Inactive Users
Inactive users cannot log in.
:::

## Password Reset

### Reset Method

Reset user password.

1. Select user
2. Click **Reset Password** button
3. Confirm

Temporary password is sent to user's email.
