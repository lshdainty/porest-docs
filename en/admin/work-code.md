# Work Code Management

Register and manage work classification codes.

::: warning Admin Only
This menu requires **WORK:MANAGE** permission.
:::

## Code List

### View Codes

View list of registered work codes.

| Item | Description |
|------|-------------|
| Code | Work classification code |
| Name | Work code name |
| Description | Code description |
| Active | Active/Inactive |

## Add Code

### Add Method

1. Click **Add Code** button
2. Enter code information
3. Click **Save** button

### Input Fields

| Field | Required | Description |
|-------|:--------:|-------------|
| Code | O | Work classification code |
| Name | O | Work code name |
| Description | - | Code description |
| Active | - | Active status |

## Edit Code

### Edit Method

1. Select code to edit
2. Click **Edit** button
3. Modify information
4. Click **Save**

### Toggle Status

Activate or deactivate codes.

1. Select code
2. Click **Toggle Status** button
3. Confirm change

::: warning Note
Deactivated codes cannot be selected by users.
Existing records using the code are preserved.
:::
