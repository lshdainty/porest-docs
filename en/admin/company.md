# Company Management

Register and manage company information.

::: warning Admin Only
This menu requires **COMPANY:MANAGE** permission.
:::

## Company Information

### Basic Information

Manage basic company information.

| Field | Description |
|-------|-------------|
| Company Name | Official company name |
| Business Number | Business registration number |
| Representative | CEO/Representative name |
| Address | Company address |
| Contact | Phone number |

### Edit Information

1. Click **Edit** button
2. Modify information
3. Click **Save** button

## Business Hours

### Set Working Hours

Set company's standard working hours.

| Field | Description |
|-------|-------------|
| Start Time | Work start time |
| End Time | Work end time |
| Break Time | Break time (e.g., 12:00-13:00) |

### Working Days

Set weekly working days.

- Monday ~ Friday (default)
- Can include Saturday/Sunday

## Logo Management

### Change Logo

Change company logo displayed in the system.

1. Click **Change Logo** button
2. Select image file
3. Click **Upload**

::: tip Recommended Size
Recommended logo size: 200x60 pixels
:::
