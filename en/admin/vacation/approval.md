# Leave Approval

Approve and manage leave requests.

::: warning Admin Only
This menu requires **VACATION:APPROVE** permission.
:::

## Pending Approval

### Pending List

View pending leave requests.

| Item | Description |
|------|-------------|
| Requester | Person requesting leave |
| Leave Type | Annual, half-day, sick leave, etc. |
| Period | Leave start ~ end date |
| Days | Number of days |
| Request Date | Date of request |
| Reason | Leave reason |

### Filter

- By department
- By leave type
- By period

## Approval Process

### Individual Approval

1. Select request to approve
2. Click **Approve** button
3. Confirm approval

### Bulk Approval

Approve multiple requests at once.

1. Check requests to approve (checkboxes)
2. Click **Bulk Approve** button
3. Confirm approval

## Rejection Process

### Rejection Method

1. Select request to reject
2. Click **Reject** button
3. Enter rejection reason
4. Click **Confirm**

::: info Rejection Reason
Rejection reason is required.
The reason is communicated to the requester.
:::

## Approval History

### View History

View approved/rejected requests.

| Item | Description |
|------|-------------|
| Requester | Person who requested |
| Leave Type | Annual, half-day, sick leave, etc. |
| Period | Leave start ~ end date |
| Process Date | Approval/rejection date |
| Result | Approved/Rejected |

## Cancel Leave

### Cancel Approval

Cancel already approved leave.

1. Select leave to cancel
2. Click **Cancel Approval** button
3. Enter cancellation reason
4. Click **Confirm**

::: warning Cancel Note
Cannot cancel leave already taken.
Can only cancel before leave start date.
:::
