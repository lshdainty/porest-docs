# Leave Policy

Configure leave accrual and usage policies.

::: warning Admin Only
This menu requires **VACATION:MANAGE** permission.
:::

## Annual Leave Policy

### Accrual Basis

Configure annual leave accrual basis.

| Setting | Description |
|---------|-------------|
| Accrual Basis | Fiscal year / Join date based |
| Accrual Timing | Lump sum at year start / Monthly |
| Base Annual Leave | Base annual days per year |

### Tenure Bonus

Configure additional leave based on years of service.

| Years of Service | Additional Days |
|------------------|-----------------|
| 3+ years | +1 day |
| 5+ years | +2 days |
| 10+ years | +3 days |

## Leave Types

### Type List

Manage available leave types.

| Item | Description |
|------|-------------|
| Type Name | Leave type name |
| Deductible | Deducts from annual leave |
| Approval Required | Requires approval |
| Active | Active/Inactive |

### Add Type

1. Click **Add Type** button
2. Enter type information
3. Click **Save** button

## Usage Restrictions

### Minimum Notice Period

Set minimum advance notice for leave requests.

- Example: Request at least 3 days before leave

### Consecutive Usage Limit

Set maximum consecutive days allowed.

- Example: Maximum 5 consecutive days

### Monthly Usage Limit

Set maximum days per month.

## Carryover Policy

### Annual Leave Carryover

Configure policy for unused annual leave.

| Setting | Options |
|---------|---------|
| Allow Carryover | Yes / No |
| Carryover Limit | Maximum carryover days |
| Expiry Period | Expiry date for carried over leave |

::: info Leave Expiration
Leave that is not carried over or past expiry date is automatically forfeited.
:::
