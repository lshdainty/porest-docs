# Leave Planning

Plan and execute leave grants.

::: warning Admin Only
This menu requires **VACATION:MANAGE** permission.
:::

## Grant Leave

### Individual Grant

Grant leave to specific user.

1. Click **Grant Leave** button
2. Select target user
3. Enter grant information
   - Leave type
   - Number of days
   - Reason
4. Click **Save** button

### Bulk Grant

Grant leave to all or specific group.

1. Click **Bulk Grant** button
2. Select targets (All / By department / By criteria)
3. Enter grant information
4. Click **Save** button

::: tip Annual Leave Grant
Use this for granting annual leave to all employees at the beginning of each year.
:::

## Grant History

### View History

View leave grant history.

| Item | Description |
|------|-------------|
| Grant Date | Date leave was granted |
| Recipient | Person receiving leave |
| Leave Type | Annual, compensatory, etc. |
| Days Granted | Number of days granted |
| Reason | Grant reason |

### Filter

- By period
- By user
- By leave type

## Deduct Leave

### Deduction Method

Deduct leave from specific user.

1. Click **Deduct Leave** button
2. Select target user
3. Enter deduction information
   - Leave type
   - Days to deduct
   - Reason
4. Click **Save** button

::: warning Deduction Caution
Deduction reduces remaining leave balance.
Cannot deduct more than remaining balance.
:::

## Leave Status

### Overall Status

View leave status for all users.

| Item | Description |
|------|-------------|
| User | User name |
| Department | Department |
| Total Granted | Granted leave days |
| Used | Used leave days |
| Remaining | Remaining leave days |

### Excel Download

Download leave status as Excel file.

1. Set search criteria
2. Click **Download Excel** button
