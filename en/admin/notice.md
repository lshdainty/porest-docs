# Notice Management

Create and manage company notices.

::: warning Admin Only
This menu requires **NOTICE:MANAGE** permission.
:::

## Notice List

### View Notices

View and manage all notices.

| Item | Description |
|------|-------------|
| Title | Notice title |
| Author | Person who posted |
| Date | Posted date |
| Views | Number of views |
| Pinned | Pinned to top |

## Create Notice

### Create Method

1. Click **Create Notice** button
2. Enter notice content
3. Click **Publish** button

### Input Fields

| Field | Required | Description |
|-------|:--------:|-------------|
| Title | O | Notice title |
| Content | O | Notice content |
| Category | - | Notice category |
| Pin | - | Pin to top of list |
| Attachments | - | Attach files |

### Rich Editor

Use rich text formatting for content.

- Bold, italic, underline
- Lists (bullet, numbered)
- Links
- Images

## Edit Notice

### Edit Method

1. Select notice to edit
2. Click **Edit** button
3. Modify content
4. Click **Save**

### Delete Method

1. Select notice to delete
2. Click **Delete** button
3. Confirm deletion

## Pin Notice

### Pin Method

Pin important notices to the top of the list.

1. Select notice
2. Click **Pin** button

::: info Pinned Notices
Pinned notices always appear at the top regardless of date.
:::
