# Introduction

## What is POREST?

**POREST** is an HR platform that designs an organizational ecosystem where People grow together like a Forest.

> "Where People Grow into a Forest — Cultivating Your Talent Ecosystem"

## Core Values

| Stage | Metaphor | Description |
|:---:|:---:|:---|
| Recruitment | Seed | Discovering talent full of potential |
| Onboarding | Settlement | Supporting new members to take root |
| Growth | Mature Tree | Growing together as solid members |

## Key Features

- **📅 Schedule Management** - Manage work and vacation schedules on a calendar
- **🏖️ Vacation Management** - Systematic management of vacation accrual and usage
- **📝 Electronic Approval** - Pre-approval and processing for extended work
- **🔐 Permission Management** - Role-Based Access Control (RBAC)

## Supported Environments

- **Web Browsers**: Chrome, Edge, Safari, Firefox (latest versions recommended)
- **Mobile**: Responsive web support
