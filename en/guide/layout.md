# Layout

## Basic Layout

The basic screen of POREST is structured as follows:

```
┌─────────────────────────────────────────┐
│              Header                      │
├──────────┬──────────────────────────────┤
│          │                              │
│  Side    │         Main Content         │
│  bar     │                              │
│          │                              │
│          │                              │
└──────────┴──────────────────────────────┘
```

## Header

- **Logo**: Click to go to home screen
- **Search**: Global search function
- **Notifications**: Check approval requests, confirmations, etc.
- **Profile**: My info, change password, logout

## Sidebar

Access main menus from the sidebar.

| Menu | Description |
|------|------|
| Home | Dashboard and calendar |
| Schedule | Register/view schedules |
| Vacation | Apply/view vacations |
| Approval | Request/approve documents |
| Admin | System management (Admin only) |

::: info Role-based Menus
Menus displayed may vary based on the logged-in user's permissions.
:::

## Main Content

Content for the selected menu is displayed.

## Language Settings

POREST supports Korean and English.

1. Click the **Profile** icon in the upper right
2. Select **Language Settings** menu
3. Select your preferred language
