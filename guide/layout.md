# 화면 구성

## 기본 레이아웃

POREST의 기본 화면은 다음과 같이 구성되어 있습니다.

```
┌─────────────────────────────────────────┐
│              상단 헤더                    │
├──────────┬──────────────────────────────┤
│          │                              │
│  사이드   │         메인 콘텐츠           │
│   바      │                              │
│          │                              │
│          │                              │
└──────────┴──────────────────────────────┘
```

## 상단 헤더

- **로고**: 클릭 시 홈 화면으로 이동
- **검색**: 전체 검색 기능
- **알림**: 결재 요청, 승인 등 알림 확인
- **프로필**: 내 정보, 비밀번호 변경, 로그아웃

## 사이드바

사이드바에서 주요 메뉴에 접근할 수 있습니다.

| 메뉴 | 설명 |
|------|------|
| 홈 | 대시보드 및 캘린더 |
| 일정관리 | 일정 등록/조회 |
| 휴가관리 | 휴가 신청/조회 |
| 전자결재 | 결재 요청/승인 |
| 관리자 | 시스템 관리 (관리자 전용) |

::: info 권한에 따른 메뉴
로그인한 사용자의 권한에 따라 표시되는 메뉴가 다를 수 있습니다.
:::

## 메인 콘텐츠

선택한 메뉴에 따라 해당 기능의 콘텐츠가 표시됩니다.

## 언어 설정

POREST는 한국어와 영어를 지원합니다.

1. 우측 상단 **프로필** 아이콘 클릭
2. **언어 설정** 메뉴 선택
3. 원하는 언어 선택
