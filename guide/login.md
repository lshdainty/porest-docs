# 로그인

## 로그인 방법

POREST에 접속하면 로그인 화면이 표시됩니다.

### 일반 로그인

1. **아이디** 입력란에 발급받은 아이디를 입력합니다
2. **비밀번호** 입력란에 비밀번호를 입력합니다
3. **로그인** 버튼을 클릭합니다

::: tip 아이디를 모르시나요?
관리자에게 문의하여 아이디를 확인하세요.
:::

### 소셜 로그인

OAuth2 기반 소셜 로그인을 지원합니다.

- Google 계정으로 로그인

## 비밀번호 변경

최초 로그인 시 또는 보안을 위해 비밀번호 변경을 권장합니다.

1. 로그인 후 우측 상단 **프로필** 아이콘 클릭
2. **비밀번호 변경** 메뉴 선택
3. 현재 비밀번호와 새 비밀번호 입력
4. **저장** 버튼 클릭

::: warning 비밀번호 규칙
- 최소 8자 이상
- 영문, 숫자, 특수문자 조합 권장
:::

## 로그아웃

1. 우측 상단 **프로필** 아이콘 클릭
2. **로그아웃** 메뉴 선택
